## 1. Executive Summary & Parity Matrix Scope

This matrix establishes an exhaustive, evidence-backed functional inventory of the existing Dependency Analyzer system before rebuilding it on the Salesforce Lightning Platform.

The matrix covers:
1. **18 View Modes** across 5 Workspace Domains (`portfolio`, `topological`, `feature`, `local`, `governance`).
2. **4 Architecture Layout Modes** (`hierarchical`, `hybrid`, `orbit`, `constellation`).
3. **Core Graph Invariants** (Selection isolation, position authority, projection isolation, layout determinism, project isolation, deep-link restoration, stale result protection, accessibility, large-graph performance).
4. **Drawers, Modals & Inspection Overlays** (`InvestigationDrawer`, `RefactorHandoffModal`, `CommandPalette`, `RefactoringSimulationPanel`, `KeyboardShortcutsModal`, `ProjectCreationModal`, `NodeHoverCard`, `EdgeHoverCard`).
5. **Persistence, Deep-Linking & Storage Contracts** (`ProjectUIState`, `localStorage`, URL query string parameters).
6. **Node.js Analysis Engine & Quality Gates** (34 CLI analysis tools, security rules, safety envelopes, debt/smell calculators).

## 4. Open Salesforce Technical Feasibility Questions (Lanes B & C)

The following features require technical resolution by **Lane B (Salesforce Architecture Feasibility)** or **Lane C (Data Model & Contracts)** before implementation:

1. **LWS/CSP Cytoscape Compatibility (Lane B):** Can Cytoscape.js v3.30.2, `cytoscape-fcose`, and canvas event listeners execute without security violation inside Lightning Web Security (LWS) in LWC?
