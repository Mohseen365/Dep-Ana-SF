### Conclusion on True Action-to-Event Correlation

The benchmark runner predicate:
```javascript
if (detail.architectureMode !== targetMode) return;
if (typeof detail.requestId === 'number' && detail.requestId <= initialReqId) return;
```
guarantees that:
1. Pre-existing layout completion events from prior runs are rejected.
2. Events generated by other architecture modes are rejected.

However, because `requestId` is generated internally inside `GraphView.tsx` (`++layoutRequestRef.current`) rather than carrying an external click correlation token, if a secondary trigger (such as a focal LWC change or background worker retry) dispatches `app:layoutcomplete` for the same `targetMode` with a higher `requestId`, the predicate will resolve. Therefore, measurements represent **monotonic completion events for the target mode**, rather than cryptographically tokenized click-to-completion click durations.

## 5. Worker Contract Findings and Parity Evidence

- **`as any` Elimination:**
  Source code inspection of `explorer/src/lib/workers/layout-worker-client.ts` (lines 273–289) confirms that `featureRegionObj` is constructed directly as a typed `: FeatureRegion` object literal. **Zero `as any` type assertions exist in `layout-worker-client.ts`**.

- **Bounds & Metadata Preservation:**
  - `width` = `sum.xMax - sum.xMin`
  - `height` = `sum.yMax - sum.yMin`
  - Degenerate bounds (`xMin === xMax`, `yMin === yMax`) correctly evaluate to `width = 0` and `height = 0`.
  - Field defaults (`nodeCount ?? 0`, `orderIndex ?? 0`, `primaryLayer || 'application'`) safely default optional worker summary properties without hiding schema errors.
  - `primaryLayer` is strongly typed as `ArchitectureLayer`.

- **Executable Parity Verification:**
  Executed via `node scripts/test-worker-geometry-contract.cjs` (Test 2):
  Compared synchronous `FeatureRegion` records against worker-deserialized `FeatureRegion` records.
  - **Normal Bounds Parity:** 100% field-by-field equality across `featureId`, `domain`, `domainId`, `xMin`, `xMax`, `yMin`, `yMax`, `xCenter`, `yCenter`, `width`, `height`, `nodeCount`, `primaryNodeCount`, `primaryLayer`, `orderIndex`.
