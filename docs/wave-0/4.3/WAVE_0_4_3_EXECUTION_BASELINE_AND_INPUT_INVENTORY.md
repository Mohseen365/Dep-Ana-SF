## 4. Evidence Classification Boundary

To eliminate the conflation of historical claims with empirical execution identified in Wave 0.4.2 review, Wave 0.4.3 enforces strict evidence categorization:

1. **Observed Facts**: Empirically measured properties of the current workspace (`HEAD SHA`, Node version, OS architecture, file SHA-256 hashes).
2. **Reported Historical Claims**: Assertions documented in earlier wave documents (e.g., memory estimates in Wave 0.4.2, test run sweeps in Wave 0.4.1) that have not been re-verified in this wave.
3. **Newly Executed Evidence**: Results generated by live execution of test runners, patch gates, and validators during Wave 0.4.3.
4. **Unverified Assertions**: Technical statements that depend on live Salesforce runtime infrastructure, browser DOM engines, or Apex compiler checks that cannot be executed offline.
5. **Missing Evidence**: Identified gaps where prior reports claimed verification but no underlying script or log existed.
