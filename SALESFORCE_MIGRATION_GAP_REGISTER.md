# Salesforce Migration Gap Register

This register details all architectural gaps, missing capabilities, and incomplete implementations identified during the repository-wide migration audit, updated as of the Central Coordinator Integration session.

## Gap Inventory & Reconciled Status

### GAP-01: Application Shell Integration of Analytical Views
- **Category:** Application UI & Feature Parity
- **Source Paths:** `scratch/salesforce-poc/force-app/main/default/lwc/daAppShell/`
- **Reconciled State:** **RESOLVED / INTEGRATED**.
- **Description:** `daAppShell` now exposes and mounts 11 approved views:
  1. `graph` (`daGraphViewer`)
  2. `matrix` (`daMatrixView`)
  3. `findings` (`daFindingsView`)
  4. `dashboard` (`daProjectDashboard`)
  5. `history` (`daAnalysisHistory`)
  6. `diagnostics` (`daDiagnosticsView`)
  7. `hotspots` (`daHotspotsView`)
  8. `radar` (`daRadarView`)
  9. `treemap` (`daTreemapView`)
  10. `subway` (`daSubwayView`)
  11. `dna` (`daArchitectureDnaBarcode`)
- In addition, the dockable `daInvestigationDrawer` is mounted and accessible across all views with interactive 1-hop drilldown preserving `SELECTION ≠ NAVIGATION`.

### GAP-02: Advanced Layout Algorithms in LWC
- **Category:** Geometry & Spatial Algorithms
- **Source Paths:** `scratch/salesforce-poc/force-app/main/default/lwc/daLayoutEngine/daLayoutEngine.js`
- **Reconciled State:** **RESOLVED / OPERATIONAL**.
- **Description:** Deterministic coordinate generation for Orbit, Constellation, Hierarchical, and Sankey layouts is implemented in pure JavaScript ES modules inside `daLayoutEngine.js`.

### GAP-03: Absent Dynamic URL State & Navigation Synchronization
- **Category:** Navigation & User State
- **Source Paths:** `daAppShell.js`, `DA_User_Preference__c`
- **Reconciled State:** **PARTIALLY RESOLVED / PERSISTED**.
- **Description:** Per-user and per-project preferences (active view mode, layout, and filter criteria JSON) are persisted to Apex `DA_User_Preference__c`. Full Lightning URL state parameter synchronization is mapped for live org Lightning Navigation PageReference configuration.

### GAP-04: Node.js Static Analysis File System Access Outside Salesforce
- **Category:** Analysis Engine & Architecture Boundary
- **Source Paths:** `scripts/dependency-analyzer.cjs`, AST parsers
- **Reconciled State:** **ARCHITECTURAL BOUNDARY PRESERVED**.
- **Description:** External static analysis parses source ASTs and generates `ExplorerDataSchema` JSON payloads; payloads are pushed into Salesforce via chunked ingestion (`DAGraphController` / `DAGraphIngestionService`) to prevent governor limit exhaustion.

### GAP-05: Refactoring Simulation & Impact Analysis
- **Category:** Interactive Workflows
- **Source Paths:** `scratch/salesforce-poc/force-app/main/default/lwc/daRefactoringEngine/`, `daInvestigationDrawer/`, `daRefactorHandoffModal/`
- **Reconciled State:** **RESOLVED / INTEGRATED**.
- **Description:** Pure topological graph computation is implemented in `daRefactoringEngine.js` (Tarjan SCC, cycle severing, node removal, class extraction). Handoff export plans (Markdown and JSON) are generated by `daRefactorHandoffModal`.

### GAP-06: Snapshot Comparison Modal UI
- **Category:** Portfolio & Comparison Workflows
- **Source Paths:** `scratch/salesforce-poc/force-app/main/default/lwc/daAnalysisHistory/`
- **Reconciled State:** **PARTIALLY IMPLEMENTED / CONTRACT DEFINED**.
- **Description:** Dual-run selection events (`runselect`, `comparelaunch`) and diff data contracts are defined in CONTRACT-05. A dedicated standalone diff modal bundle is deferred pending coordinator path allocation.

### GAP-07: Sankey Dependency River Static Resource Bundling
- **Category:** Advanced Visualizations
- **Source Paths:** `scratch/salesforce-poc/force-app/main/default/lwc/daSubwayView/`, static resources
- **Reconciled State:** **DEFERRED PENDING COORDINATOR APPROVAL**.
- **Description:** Dependency river math is mapped in `daLayoutEngine`. Standalone SVG Sankey rendering bundle deferred to prevent unapproved external D3 static resource injections.
